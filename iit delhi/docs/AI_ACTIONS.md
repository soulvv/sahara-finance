# Sahara Finance — AI Action Lifecycle & Intent Registry

## 1. Action Lifecycle

Every conversational action generated by the OmniDimension Saathi agent undergoes a strict state machine lifecycle:

```
[ AI Proposal ]
       │
       ▼
[ Action ID Generation & Nonce Assignment ]
       │
       ▼
[ Payload & Schema Validation ]
       │
       ▼
[ User Ownership & Multi-Tenant IDOR Check ]
       │
       ▼
[ Policy Engine & Risk Level Assessment ]
       │
       ▼
[ Expiration Window Check (5-minute TTL) ]
       │
       ▼
[ User Explicit Confirmation (Swipe-to-Pay / Modal) ]
       │
       ▼
[ Deterministic Domain Service Execution ]
       │
       ▼
[ Immutable Audit Trail Event Logged ]
```

## 2. Intent Registry & Entity Normalization

Sahara supports extensive vernacular entity parsing across Hindi, Hinglish, and English:

### Normalized Spoken Amounts
- Spoken text: *"Rahul ko paanch sau bhejo"* -> `{ intent: "PREPARE_PAYMENT", recipient: "Rahul", amount: 500, currency: "INR" }`
- Spoken text: *"Send five thousand rupees"* -> `{ intent: "PREPARE_PAYMENT", amount: 5000, currency: "INR" }`
- Spoken text: *"राहुल को ५०० रुपये भेजो"* -> `{ intent: "PREPARE_PAYMENT", amount: 500, currency: "INR" }`

### Ambiguity Handling
When numeric ambiguity arises between orders of magnitude (e.g., ₹500 vs ₹5,000 due to acoustic compression), Sahara triggers numeric disambiguation dialog:
> *"Aap ₹500 keh rahe hain ya ₹5,000?"*
