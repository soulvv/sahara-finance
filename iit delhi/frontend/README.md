# Sahara Finance Frontend
React 19 + TypeScript + Vite + Tailwind CSS v4 PWA designed for vernacular financial literacy.

## Setup & Running

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server (Port 3000):**
   ```bash
   npm run dev
   ```

3. **Production Build:**
   ```bash
   npm run build
   npm run preview
   ```

4. **API Proxy:**
   Vite is pre-configured to proxy all `/api/*` requests to the backend at `http://localhost:5000`.
